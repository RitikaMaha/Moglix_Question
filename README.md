# Longest Valid Parentheses

## Problem Statement

Given a string containing only '(' and ')', return the length of the longest valid (well-formed) parentheses substring.

### Example

Input:
(()())

Output: 6

## Solutions

### 1. Brute Force
- Time Complexity: O(n²)
- Space Complexity: O(1)

### 2. Optimal (Stack)
- Time Complexity: O(n)
- Space Complexity: O(n)
